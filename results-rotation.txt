== 共有鍵: ntpdrs で発行した cookie を両方で使う (NLB が交互に振り分ける想定)
id_offset=0 primary=0 key_ids=[0] primary_id=0
fetch v1: HTTP 200 cookie_key_ids=[0]
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
query v1 -> ntpdrs: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
== 段階 1: 新しい鍵を足す (primary は旧鍵のまま)
id_offset=0 primary=0 key_ids=[0, 1] primary_id=0
  (restarted ntpdrs)
query v1 -> ntpdrs: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
  (restarted ntpdrs2)
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0]
== 段階 2: 新しい鍵を primary に
id_offset=0 primary=1 key_ids=[0, 1] primary_id=1
  (restarted ntpdrs)
fetch v2: HTTP 200 cookie_key_ids=[1]
query v2 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0, 1]
query v1 -> ntpdrs: ok=4/4 refetched_from_api=0 cookie_key_ids=[0, 1]
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0, 1]
  (restarted ntpdrs2)
query v1 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[0, 1]
query v2 -> ntpdrs: ok=4/4 refetched_from_api=0 cookie_key_ids=[0, 1]
== 段階 2 と 3 の間: 車両が通常どおり問い合わせ、手持ちの旧鍵 cookie が新鍵 cookie に入れ替わる
query v1 -> ntpdrs: ok=8/8 refetched_from_api=0 cookie_key_ids=[1]
query v2 -> ntpdrs2: ok=8/8 refetched_from_api=0 cookie_key_ids=[1]
== 段階 3: 旧鍵を捨てる
id_offset=1 primary=0 key_ids=[1] primary_id=1
  (restarted ntpdrs)
  (restarted ntpdrs2)
query v1 -> ntpdrs: ok=4/4 refetched_from_api=0 cookie_key_ids=[1]
query v2 -> ntpdrs2: ok=4/4 refetched_from_api=0 cookie_key_ids=[1]
== 対照: 旧鍵の cookie しか持たない車両 (段階 1 の前に取得し、以後問い合わせていない)
query stale -> ntpdrs: ok=4/4 refetched_from_api=1 cookie_key_ids=[1]
